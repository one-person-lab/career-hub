# 设计案例

**幂等性设计如何实现？**

通过redis缓存并设置过期时间，对请求的方法及参数进行md5加密，当请求一致时则可以忽略掉重复的请求。

#### **权限认证是如何实现的？**

RBAC（Role-Based Access Control）基于角色的访问控制，用户、角色、权限

表结构（用户表、角色表、权限表、菜单表、用户角色表、角色权限表、角色菜单表）

#### **单点登录是怎么实现的？**

Single Sign On（SSO），只需要登录一次，就可以访问所有信任的应用系统。使用JWT或者Oauth2。

浏览器下单经过网关校验token是否有效，授权失败则跳转登录页面，发起登录请求网关路由到登录服务，校验成功返回token（JWT生成），浏览器把token写入cookie。
