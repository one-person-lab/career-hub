# 前端基础

# 环境

## Mac安装homebrew

```
brew --version

brew install nvm

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

  

## Node安装

```
# Linux安装nvm两种方式
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.3/install.sh | bash
wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.3/install.sh | bash

# Windows安装
https://github.com/coreybutler/nvm-windows/releases?spm=5176.28103460.0.0.297c451e7E2F4w

nvm --version

# 所有可用版本
nvm ls-remote --lts
nvm list available

# 当前已安装版本
nvm ls

nvm use 14.17.0

nvm install 16.20.2  # 安装最新的16.x版本
nvm install 18.20.7  # 安装最新的18.x版本

node --version

# 国内环境经常下载不了官方源，可以切换到淘宝镜像：
# Windows
nvm node_mirror https://mirrors.cloud.tencent.com/nodejs-release/
nvm npm_mirror https://mirrors.cloud.tencent.com/npm/

# Linux
nvm node_mirror https://npmmirror.com/mirrors/node/
nvm npm_mirror https://npmmirror.com/mirrors/npm/

```

## Vue启动

```
# 执行失败时需要在cmd中执行
cd yudao-ui-admin
# 安装 Yarn，提升依赖的安装速度
npm install --global yarn

# 安装依赖
yarn install

# 启动服务
npm run local
# 打包
npm run build:dev

初始密码
admin/admin123
```

```
# 执行失败时需要在cmd中执行
# 安装 pnpm，提升依赖的安装速度
npm config get registry

npm config set registry https://registry.npmjs.org
npm config set registry https://registry.npmmirror.com

npm install -g pnpm
# 安装依赖
pnpm install

# 启动服务
npm run dev
# 打包
npm run build:dev
```
