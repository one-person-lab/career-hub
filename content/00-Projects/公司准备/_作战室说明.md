# 公司准备

> 一句话：一家公司一页。从「要不要投」到「面试完复盘」的全过程。

## 一页写什么

| 段落 | 内容 |
|------|------|
| 公司情报 | 业务、技术栈、团队规模、最近在做什么 |
| 岗位对照 | 拿 `content/目标岗位/` 里的画像来对，标出这家额外多要什么 |
| 这张卷子怎么答 | 从项目成果里挑哪 3 张卡、按什么顺序讲 |
| 我准备反问的问题 | 3–5 个，按「团队 / 业务 / 技术 / 发展」分 |
| 状态 | 待投 / 已投 / 面试中 / 已复盘 / 已结束 |
| 时间线 | 每一步的日期与结果 |

## 为什么值得单独开一页

投递量不大的时候（个位数），贵精不贵多。一页公司情报的价值：

- **面试时那句「我看了你们最近在做 XX」** —— 90% 的候选人说不出这句
- **复盘时**，你能分清「是我准备不够」还是「这家根本不适合」

## 状态怎么流转

```
待投 → 已投 → 面试中 → 已复盘 → （Offer / 已结束）
```

每次改状态都补一条时间线记录和当时的判断。半年后回来看，你会知道自己当初为什么做那个决定。

## 一个硬边界

> ⚠️ 这一页是**内部准备材料**，不是给面试官看的。
>
> 如果要对外展示（比如做一份定制页给面试官看），只放「能力匹配 + 我能为你解决什么」，
> **不要**把「我的反问清单」「我对这家公司的判断」「薪资预期」放进去。
>
> 对外那一份请单独放在作品集里，不要从这个目录直接抄。

## 怎么加一家

在本目录下新建 `<公司名>-<岗位>.md`。
