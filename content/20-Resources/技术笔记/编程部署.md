# 快捷键

## 代码编辑

-   代码补全：

-   `Ctrl + Space`：基本补全
-   `Ctrl + Shift + Space`：智能补全（根据上下文）

-   生成代码：

-   `Alt + Insert`：生成代码（如构造函数、getter/setter 等）

-   格式化代码：

-   `Ctrl + Alt + L`：格式化代码

-   优化导入：

-   `Ctrl + Alt + O`：优化导入（移除未使用的导入）

-   注释：

-   `Ctrl + /`：行注释
-   `Ctrl + Shift + /`：块注释

-   删除行：

-   `Ctrl + Y`：删除当前行

-   复制行：

-   `Ctrl + D`：复制当前行

-   移动行：

-   `Alt + Shift + ↑/↓`：上下移动当前行

-   展开/折叠代码：

-   `Ctrl + +`：展开代码块
-   `Ctrl + -`：折叠代码块

-   撤销：

-   `Ctrl + Z`：撤销上一次操作

-   重做：

-   `Ctrl + Shift + Z`：重做被撤销的操作

-   查找文本：

-   `Ctrl + F`：在当前文件中查找

-   全局查找文本：

-   `Ctrl + Shift + F`：全局查找

-   替换文本：

-   `Ctrl + R`：在当前文件中替换

-   全局替换文本：

-   `Ctrl + Shift + R`：全局替换

-   快速修复：

-   `Alt + Enter`：快速修复（如导入类、修复错误等）

-   查看文档：

-   `Ctrl + Q`：查看光标处代码的文档

-   查看参数信息：

-   `Ctrl + P`：查看方法参数信息

-   后退：`Ctrl + Alt + ←`
-   前进：`Ctrl + Alt + →`

## 导航

-   查找类：

-   `Ctrl + N`：查找类

-   查找文件：

-   `Ctrl + Shift + N`：查找文件

-   查找符号：

-   `Ctrl + Alt + Shift + N`：查找符号（方法、变量等）

-   查找操作：

-   `Ctrl + Shift + A`：查找操作（快捷键或菜单项）

-   跳转到声明：

-   `Ctrl + B`：跳转到声明处

-   跳转到实现：

-   `Ctrl + Alt + B`：跳转到实现处

-   查看类结构：

-   `Ctrl + F12`或 `Ctrl + Shift + O`：查看当前类的成员

-   查看调用层次：

-   `Ctrl + Alt + H`：查看方法的调用层次

-   最近文件：

-   `Ctrl + E`：查看最近打开的文件

-   查看字段引用：`Alt + F7` 或 `Ctrl + 鼠标点击`
-   定位当前文件： `Ctrl + Shift + \`
-   转到括号： `Ctrl + Shift + M`

## 重构

-   重命名：

-   `Shift + F6`：重命名

-   提取变量：

-   `Ctrl + Alt + V`：提取变量

-   提取方法：

-   `Ctrl + Alt + M`：提取方法

-   提取常量：

-   `Ctrl + Alt + C`：提取常量

-   内联：

-   `Ctrl + Alt + N`：内联变量或方法

## 调试

-   调试控制：

-   `F9`：继续执行程序，直到下一个断点。
-   `Ctrl + F2`：停止调试会话。
-   `Ctrl + F5`：重启当前调试会话。

-   启动调试：

-   `Shift + F10`：运行当前配置
-   `Shift + F9`：调试当前配置

-   单步调试：

-   `F8`：单步跳过
-   `F7`：单步进入
-   `Alt + Shift + F7`：强制进入方法内部（即使是库代码）。
-   `Shift + F8`：单步跳出
-   `Alt + F9`：运行程序直到光标所在的行。

-   断点操作：

-   `Ctrl + Shift + F8`：查看所有断点
-   `Ctrl + F8`：在当前行添加或移除断点。
-   `Alt + F8`：打开表达式评估窗口，可以计算变量或表达式的值。

​  

## 版本控制

-   提交更改：

-   `Ctrl + K`：提交代码

-   更新项目：

-   `Ctrl + T`：更新项目

-   查看变更：

-   `Alt + 9`：打开版本控制窗口

```
node --version

# Linux

nvm npm_mirror https://npmmirror.com/mirrors/npm/

```
