# 上线问题

# 前端

## Nginx配置

```
server {
    try_files $uri $uri/ /index.html;
}
```

```

    #allow 192.168.1.x;
```

## 替换地址

```
cd /www/wwwroot/xxx/dist/static/js/ && find . -name "*.js" -exec sed -i 's|http://old|http://new|g' {} \; && echo "API地址替换完成！" 

cd /www/wwwroot/xxx/web/static/js/ && find . -name "*.js" -exec sed -i 's|http://old|http://new|g' {} \; && echo "API地址替换完成！" 

cd /www/wwwroot/xxx/dist/static/js/ && \
n=$(grep -R "http://old" . --include="*.js" | wc -l) && \
sed -i 's|http://old|http://new|g' $(find . -name "*.js") && \
echo "API地址替换完成，共替换 $n 处"
```

## 指定配置文件

```
--spring.config.location=/www/wwwroot/【网站名】/config/application.yaml,/www/wwwroot/【网站名】/config/application-dev.yaml
```

注意：如果后端使用域名访问，需要在网站设置中开启外网映射

## 替换文件地址

```
SELECT id, image
FROM mg_product
WHERE image LIKE 'https://doc.old.live/%';

UPDATE mg_product
SET image = REPLACE(
    image,
    'https://doc.old.live',
    'https://doc.new.live'
)
WHERE image LIKE 'https://doc.old.live/%';

SELECT id, url
FROM infra_file
WHERE url LIKE 'https://doc.old.live/%';

UPDATE infra_file
SET url = REPLACE(
    url,
    'https://doc.old.live',
    'https://doc.new.live'
)
WHERE url LIKE 'https://doc.old.live/%';
```

# 数据文件导入

进入 MySQL：

> mysql -uroot -p

执行：

> SHOW VARIABLES LIKE 'secure\_file\_priv';

编辑配置文件/etc/my.cnf：

找到 `[mysqld]` 段，在里面添加一行：

```
secure_file_priv=
```

重启Mysql：

> systemctl restart mysqld
