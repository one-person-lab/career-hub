# Skill

@豆包: 整理好的WorkBuddy必装8个实用skill：

1.  Find Skill：说需求自动匹配对应技能
2.  Browser Use：自动操作网页填表单，一句话搞定繁琐操作
3.  Skills Scanner：装第三方skill前检测危险脚本、多余权限
4.  Human writing：去掉AI写作痕迹，文字更贴近真人风格
5.  Agent Reach：全网搜信息找选题素材做调研，效率翻倍
6.  归藏PPT：一句话生成带22种布局和动态效果的网页PPT
7.  MarkItDown：各类文件转成Markdown，方便AI处理资料
8.  Skill creator：找不到合适技能可以直接定制专属款  
    作者还整理了全部安装教程，还有10个视频没提到的额外skill资源可以获取
